## v0.1.0 —— 首个发布版

**定位**：Vue 3 SPA + 自建 Laravel 后端（酷我音源插件化，契约与认证形态对齐 SqMusic：信封响应 + token），另接入 fnOS NAS 本地曲库。前端以 Docker 镜像 + CI 发布，后端独立部署（含队列 worker）。

### 搜索与浏览

- 搜索页：音源下拉（插件列表驱动，兜底「酷我」）、联想词（300ms 防抖取前 8）、搜索历史（本地 10 条，去重、可单删/清空）、关键词与 URL `?q=` 双向同步（结果可刷新恢复/分享）、每页 30 条分页
- 音质徽标：`brType` 本地解析 + 音质枚举表优先，按码率降序取前 3；无损紫 / ≥320K 蓝 / 其余灰
- 歌手页：歌手照片与统计徽标、全部歌曲（50 条/页「加载更多」、按 id 去重）、全部专辑网格（悬浮下载整张）、下载全部专辑（确认框）、简介净化折叠
- 专辑页：头部大图与发行信息、曲目列表按碟号/曲号排序、播放整张、下载整张（音质下拉来自曲目码率汇总）、正在播放本专辑标记

### 播放器

- 播放队列：单曲播放 / 整组连播，队列位置展示，跨页面持久（路由切换不中断）
- 直链懒加载：切到哪首才取直链（最高音质），响应竞态丢弃，避免直链过期
- 播放条：进度拖拽、音量与静音、自动切歌（队尾停止）、播放失败 toast
- 播放模式：列表循环 / 随机 / 播完停止
- 全局快捷键：空格播放暂停、`/` 聚焦搜索、Ctrl+←/→ 切歌、Ctrl+↑/↓ 音量；`?` 唤出快捷键速查弹窗
- 音量持久化（刷新恢复）
- 歌词弹窗：LRC 解析、无内容兜底提示

### fnOS 本地音乐库

- 接入：同源 `/fnos` 反代直连 NAS 内置音乐应用；静默登录（密码 SHA-256），会话失效自动重登
- 首页快捷播放导向：曲库总数 hero + 大搜索框 + 「随便听听」（随机 30 首整组连播）+ 最近添加（12 张封面卡）+ 最近播放（本地记录 20 条）
- 库内搜索：歌曲 + 专辑 + 歌手并行检索，**回车直接整组播放命中歌曲**
- 浏览：歌曲 / 专辑 / 歌手 / 流派 / 歌单五类分页浏览
- 合集页：专辑/歌手/流派/歌单共用头部信息 + 曲目列表 + 播放全部 + 加载更多
- fnOS 歌词（LRC 复用歌词弹窗）；本地曲目适配统一模型，不可下载（隐藏下载入口）

### 下载

- 服务器下载队列：单曲（可选音质，省略取最高）/ 专辑（整数码率）/ 歌手全部专辑，均带确认与 toast
- 浏览器直链下载：`<a download>` 触发保存，文件名 `歌手 - 歌名.格式`；每首歌下载菜单分「服务器队列 / 浏览器直链」两组
- 下载任务页：5 秒轮询 + 手动刷新、按状态筛选、状态徽标（等待/下载中/解析中闪烁/成功/失败）、单条操作（失败重试 / 重新入队 / 删除）、批量操作（重试全部失败、按状态删除）、分页
- 全局完成通知：15 秒轮询检测「进行中 → 成功/失败」迁移，跨页面聚合 toast（首次建档不刷屏，失败附后端消息）

### 设置与基础设施

- 系统设置独立成页：通用 / 后端连接分区，连接状态指示（绿点/红点 + 错误横幅），按设备覆盖连接配置
- 版权信息分区与 MIT LICENSE
- PWA：自动更新、SPA 预缓存、`/api/*` 与 `config.json` 永不缓存、封面 StaleWhileRevalidate（200 条/14 天）
- 深色模式（持久化）、启动页品牌化
- 技术底座：Pinia 三 store（app/player/fnos）、axios 统一封装（动态 baseURL/token 头/信封解包/403 自动重登）、异步请求卸载守卫防路由竞态

### 后端（server/，Laravel）

- 酷我音源插件化：歌曲/歌手/专辑搜索、联想词、歌词、直链解析
- 服务器下载队列：任务状态机、重试、失败消息；SQLite 存储
- API 文档：Scalar + Scramble 在线测试台；OpenAPI 规范固化 + `packages/api-contract` 契约类型包（openapi-typescript 生成）

## v0.2.0 —— 自建后端完全替代 · download-only · 安全加固

**定位**：v0.2.0 起自建后端**完全替代** SqMusic（契约与认证残留清理干净，无认证、连接即用）；刮削功能随 download-only 转型移除，下载目录模板下沉到 server worker；monorepo 布局与两容器部署拓扑定型；一轮完整安全加固。

### 后端与契约（破坏性变更）

- **SQMusic 退役**：SqMusic 契约残留与认证体系整体移除——前端登录概念消失（token/403/凭据配置不复存在），探活唯一 `/api/healthcheck`
- **酷我数据清洗**：上游 HTML 实体解码（外文歌手名 `&nbsp;` 等）、专辑搜索分页兜底修正
- **下载目录模板**：`MC_MUSIC_DOWNLOAD_PATH_TEMPLATE`（如 `{artist}/{album}/{title}.{ext}`），server 端 PHP 原生实现，下载完成自动按 歌手/专辑/ 结构归位；模板不含目录部分时平铺（详见[下载与目录布局](./download.md)）
- 注：本周期曾交付刮削增强（ID3 写年份/音轨号、Deezer + Last.fm 流派补全、写标签后重排），随 download-only 转型整体移除，未进入发布形态

### 部署与架构（定型为最终拓扑）

- **monorepo 落地**：前端 `web/`、文档站 `docs/`（VitePress）、契约 `packages/api-contract`，根目录无 package.json
- **两容器拓扑**：server-worker 并入 server 容器（entrypoint 监管 worker，自愈 + 优雅收尾）；对外唯一入口 web 反代 `server:17017`（后端端口不再暴露宿主），详见[Docker 部署](./deployment.md)
- **server 镜像 CI 发布**（`music-copilot-server`），默认镜像源切 GHCR
- **compose 零必填配置**：API 地址默认指向 server 容器、端口默认值，变量全部显式 `environment`，数据 bind mount `./data` + `./downloads`
- 分支模型收敛 development 单线
- 队列可靠性：`retry_after` 对齐任务超时、中断任务可恢复、serve 崩溃自愈
- 版本指纹修复：镜像构建预生成 build-info，修复线上版本信息降级为 dev

### 安全加固

- XSS：富文本净化换 DOMPurify 白名单；浏览器直链只放行 http(s) 协议
- 下载链路纵深加固：不可信数据落地面收敛
- 批量任务端点 GET→POST（防网页 drive-by 触发）+ `api/*` 全局限速
- 部署加固：构建上下文收窄、web 容器 healthcheck、配置生成转义兜底
- **fnOS 凭据代持**：`/api/fnos/login|logout` 由 server 代登录，token 经 HttpOnly Cookie 下发；前端不再接触密码与 token，运行时配置彻底不含凭据

### 前端功能与 UI 改版

- 音乐库：tabs 模式（视口锁定 + 内容内部滚动）、卡片网格一行 6 个、搜索 hero 改工具栏布局
- 歌手页：全部歌曲按播放次数（热度）降序、全部专辑一行 10 张可展开收起、区块顺序改为专辑在下
- 专辑页：简介并入头部信息块右栏、曲目列表增加标题
- 播放器：播放条新增播放模式切换按钮、播放中标记改均衡器动效、桌面端行操作悬停浮现
- 布局与视觉：首页搜索按钮内嵌搜索框、导航栏加首页入口（首页-音乐库-下载任务）、搜索页/任务页锁定视口高度内部滚动、滚动条自动隐藏、专辑封面统一圆角方形、窄屏导航收敛图标、启动页品牌化、Toast 体系统一
- 任务页精简：移除消息与插件列、歌单列表去音质标签

### 修复

- 酷我逐字时间轴歌词解析失败（行时间以 `[mm:ss.xx]` 为准）
- 音乐库合集详情页补「← 返回」导航（死端回归）
- 下载重排兼容 WSL `/mnt/c` stat 延迟（避免静默平铺）
- 前端竞态与交互缺陷批量修复（含卸载守卫补齐）

### 文档站

- 指南区重组：快速开始 / 本地开发 / Docker 部署 / 配置说明；架构分组新增 web、server 两页；部署文档新增「安全边界」段

## v0.3.0 —— API V2

**定位**：后端 API 整体升级为 V2 REST 契约，前端全量切换；镜像发布 `0.3` / `0.3.0` / `latest` tag。

### API V2（破坏性变更）

- REST 化 `/api/v2/*`：真 HTTP 状态码、裸 JSON 响应、错误体统一 `{error, message}`
- 数值语义：一律整数；统一分页 `{items, total, page, pageSize}`；统一 Song 模型（`duration` 毫秒）
- 旧信封端点全部删除（`/api/healthcheck` 唯一保留信封作探活）
- 响应结构收敛到 `app/Http/Resources/V2/`；OpenAPI 规范固化重导出，`packages/api-contract` 契约类型重新生成
- 前端整体切换 V2：后端调用收敛 `web/src/api/` 统一 `request()`（直返响应体，错误靠状态码判别）

### 修复与 CI

- 下载任务「更新时间」按本地时区显示（此前时区偏移）
- 新建下载任务大小列恒空——SongResource 透传 `dataInfo`
- CI 修复：web 镜像构建注入 `packages/api-contract` 契约上下文
